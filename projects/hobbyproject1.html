Fruit Freshness Classifier

AI & Machine Learning

Overview

The Fruit Freshness Classifier is a deep learning–based computer vision project designed to classify fruit images into three categories: Fresh, Okay, and Avoid. The goal of the project is to automate fruit quality assessment using image-based analysis, reducing manual inspection and improving consistency. The system is built using a ResNet50 convolutional neural network with transfer learning, trained on labeled fruit images. After training, the model is deployed using FastAPI, allowing users to upload an image through an API endpoint and receive real-time predictions. The project covers the complete machine learning lifecycle — data preprocessing, model training, evaluation, and deployment — and demonstrates practical skills in deep learning, computer vision, and API-based model serving.

Tech Stack

  • Languages: Python
  • ML Model: ResNet50 (Transfer Learning)
  • Deep Learning Framework: PyTorch, Torchvision
  • Image Processing: Pillow (PIL), OpenCV
  • Data Handling: NumPy
  • Backend / API: FastAPI
  • Server: Uvicorn
  • Deployment: Local Deployment (API-based)

My Contributions

  • Designed and implemented an end-to-end image classification pipeline for fruit freshness detection
  • Applied transfer learning using a pre-trained ResNet50 model for binary classification (Fresh vs Rotten)
  • Built custom data preprocessing and augmentation workflows for image datasets
  • Trained, validated, and evaluated the deep learning model using PyTorch
  • Developed a FastAPI-based backend to upload images and return real-time predictions

Conclusion

This project demonstrates the practical application of deep learning in food quality assessment. By accurately classifying fruits as fresh or rotten using image-based analysis, the system helps reduce food waste and supports smarter decision-making in retail and supply chain environments. The solution is scalable, efficient, and suitable for real-world deployment through an API-based interface.
